Pandas is a python module used in data analysis. It is used for data manipulation and the most useful Pandas functions is creating dataframes and can be used to read and write csv files using `pandas.DataFrame()`, `pandas.read_csv()`, and `pandas.to_csv()` (although typically `pandas` is imported using an abbreviation `import pandas as pd` in most textbooks. In my experience working with Pandas, I find it indispensible for data analysis using Python, and more intuitive and versatile than any packages/libraries available in R. The most useful Pandas functions, other than the ones already mentioned, are `pandas.pivot()`, `pandas.melt()`, and `pandas.concat()`, which allow to manipulate different views and merge between datasets.
